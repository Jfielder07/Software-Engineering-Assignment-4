Instructions for using program:
-Must have python 3.10 or newer installed
-install the files, then run the following command after navigating to wherever you have the files located:

python -m pip install -r requirements.txt

Then, create a doctor account:
python bootstrap_staff.py --username doctor1 --role doctor

start the application:
python web_app.py

Then, open a web browser and navigate to:
http://127.0.0.1:5000
